# 🛒 FoodStore

**FoodStore** es un proyecto de Programación 3 sobre una tienda de comidas rapidas en la cual se puede administrarla y los usuarios realizar compras. Desarrollada con un enfoque sobre simplicidad y funcionalidad. Utiliza una arquitectura de JavaScript Vanilla potenciada por **Vite** para una experiencia de desarrollo moderna y rápida.

## 🚀 Tecnologías Utilizadas

*   **Entorno de Desarrollo:** [Vite](https://vitejs.dev/)
*   **Lenguaje:** TypeScript / JavaScript (Vanilla)
*   **Estilos:** HTML5 & CSS3
*   **Gestor de Paquetes:** pnpm

## 🛠️ Requisitos Previos

Para ejecutar este proyecto es necesario tener instalado:

1.  **Node.js** (Versión 18 o superior)
2.  **pnpm**
